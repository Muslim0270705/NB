# ✂️ NS Barber Studio — сайт барбершопа

Одностраничный сайт с онлайн-записью и админкой для **NS Barber Studio** (Бишкек, мкр. Восток-5, 2/2).
Сделан по ТЗ на той же архитектуре, что и Nomad College: **Astro + React-острова + Tailwind v4, Feature-Sliced Design**.

## Что внутри

| Раздел ТЗ                                                                                        | Где в коде                                 |
| ------------------------------------------------------------------------------------------------ | ------------------------------------------ |
| Главная: логотип, слоган, обложка, «Записаться», краткие услуги, адрес/телефон, Instagram и 2ГИС | `widgets/hero`                             |
| Услуги и цены по категориям, кнопка записи у каждого блока (сразу выбирает услугу в форме)       | `widgets/price-list`                       |
| О студии: концепция, ценности, интерьер, мастера                                                 | `widgets/about`                            |
| Галерея с фильтром и лайтбоксом (клавиши ←/→/Esc)                                                | `widgets/gallery`                          |
| Отзывы + рейтинг 2ГИС                                                                            | `widgets/reviews`                          |
| Онлайн-запись: имя, телефон, услуга, мастер, дата, время + WhatsApp / Instagram Direct           | `widgets/booking`, `features/booking-form` |
| Контакты: виджет карты 2ГИС, кликабельный телефон, часы, мессенджеры, форма обратного звонка     | `widgets/contacts`                         |
| Кнопка «Записаться» всегда под рукой (шапка + фиксированная панель на телефонах)                 | `widgets/header`, `widgets/mobile-cta`     |
| Админка: заявки, цены и услуги, галерея, мастера, отзывы, контакты и часы                        | `/admin`, `widgets/admin-panel`            |

Технические требования: адаптивная mobile-first вёрстка, SEO (H1–H3, meta, Open Graph, schema.org `BarberShop`,
`sitemap.xml`, `robots.txt`, favicon), антиспам формы (скрытое поле + время заполнения + лимит по IP),
уведомления о заявках в Telegram, Google Analytics / Яндекс.Метрика по переменным окружения,
автосжатие загружаемых фото в WebP.

## Архитектура (FSD)

```
src/
├── app/          # Layout.astro (SEO, аналитика, анимации), AdminLayout, global.css — токены бренда
├── pages/        # index (SSR), admin/*, api/* (запись, админ-API), uploads/[file], sitemap.xml
├── widgets/      # Секции страницы и админ-панель
├── features/     # booking-form — форма записи / обратного звонка
├── entities/     # content (услуги, мастера, галерея, контакты) и booking (заявки, слоты)
└── shared/       # ui (лого, иконки, кнопки), lib (ссылки, маска телефона), server (хранилище, auth, Telegram, фото)
```

Данные (контент, заявки — по файлу на заявку, фото) хранятся в `shared/server/store.ts`:
локально и в Docker — файлы в `DATA_DIR` (по умолчанию `./data`), на Netlify — в **Netlify Blobs**
(диск серверлесс-функций не сохраняется). Хранилище и адаптер выбираются при сборке по `NETLIFY=true`.
Пока админка ни разу не сохраняла — сайт показывает стартовое наполнение из `entities/content/model/defaults.ts`.

## Деплой на Netlify

Репозиторий подключается к Netlify как обычно — `netlify.toml` уже задаёт сборку. Адаптер `@astrojs/netlify`
превращает страницы и API в функции, данные хранятся в Netlify Blobs (включены по умолчанию, настраивать не нужно).

В **Site configuration → Environment variables** добавьте:

| Переменная                               | Зачем                                                  |
| ---------------------------------------- | ------------------------------------------------------ |
| `ADMIN_PASSWORD`                         | пароль входа в `/admin` (без него админка закрыта)     |
| `SESSION_SECRET`                         | длинная случайная строка (`openssl rand -hex 32`)      |
| `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID` | уведомления о заявках (необязательно)                  |
| `PUBLIC_GA_ID`, `PUBLIC_YM_ID`           | аналитика (необязательно)                              |
| `SITE_URL`                               | когда подключите домен, например `https://nsbarber.kg` |

После изменения переменных запустите **Deploys → Trigger deploy**.

## Запуск

```bash
pnpm install
cp .env.example .env   # задайте ADMIN_PASSWORD и SESSION_SECRET
pnpm dev               # http://localhost:3000 (или следующий свободный порт)
```

Сборка и прод: `pnpm build && pnpm start`. Docker:

```bash
docker build -t ns-barber .
docker run -d -p 80:80 -v ns-data:/app/data \
  -e ADMIN_PASSWORD=... -e SESSION_SECRET=... \
  -e TELEGRAM_BOT_TOKEN=... -e TELEGRAM_CHAT_ID=... \
  ns-barber
```

HTTPS (SSL) и домен (`nsbarber.kg`) настраиваются на reverse-proxy (Nginx/Caddy) перед контейнером.
Если домен будет другим — поменяйте `site` в `astro.config.mjs` и строку `Sitemap` в `public/robots.txt`.

## Инструкция для администратора

1. Откройте `https://<домен>/admin`, введите пароль.
2. **Заявки** — новые записи и обратные звонки. Позвонить / написать в WhatsApp одной кнопкой, сменить статус.
   Список обновляется сам раз в минуту.
3. **Услуги и цены** — правка названий и цен, добавление/удаление, порядок стрелками.
4. **Галерея** — «Выбрать фото» (можно несколько), подпись и категория. Первое фото «Интерьер» становится обложкой главной.
5. **Мастера** — имя, роль/опыт, фото. Мастера попадают и в форму записи.
6. **Отзывы** — рейтинг 2ГИС и избранные отзывы гостей.
7. **Контакты** — адрес, телефон, WhatsApp, Instagram, часы работы (по ним строятся слоты записи).
8. После правок нажмите **«Сохранить»** — изменения появятся на сайте в течение минуты.

### Уведомления в Telegram

1. Создайте бота у @BotFather, получите токен.
2. Добавьте бота в чат администратора, напишите в чат любое сообщение.
3. Откройте `https://api.telegram.org/bot<токен>/getUpdates`, возьмите `chat.id`.
4. Задайте `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID` и перезапустите сервер.
